# AgroGuide

AgroGuide is a crop recommendation app that compares a field profile against preferred crop conditions using normalized scoring across soil and climate readings.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Project notes

- React + Vite frontend
- Explainable crop matching based on seven field signals
- Quick-start sample field profiles
- Responsive layout for local field planning

## Deploy to GitHub Pages or a static host

```bash
npm run build
```

Upload the generated `dist` folder to your preferred static host.
